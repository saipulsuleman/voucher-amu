📊 Sinkronisasi Otomatis Google Sheets

Masukkan URL Web App Google Apps Script dari Google Sheet Baru Anda untuk sinkronisasi otomatis laporan transaksi real-time (upsert in-place & anti-duplikasi).

📋 Panduan Setup Google Sheet Baru

  1. Buka sheets.new untuk membuat Google Sheet baru di Drive Anda.
  2. Buka menu Ekstensi -> Apps Script.
  3. Hapus seluruh kode default di Code.gs, lalu salin dan tempelkan skrip di bawah ini.
  4. Klik tombol Terapkan (Deploy) -> Penerapan Baru (New Deployment).
  5. Pilih jenis: Aplikasi Web (Web App), Pengontrol: Saya (Me), Akses: Siapa saja (Anyone).
  6. Klik Terapkan, izinkan akses Google Account jika diminta, lalu salin URL Web App yang dihasilkan ke dalam form pengaturan aplikasi ini.
